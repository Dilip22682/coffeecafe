# ☕ Coffee Cafe - Django Web Application

A simple **Coffee Cafe ordering web application** built using **Django, Python, HTML, CSS, and Bootstrap**.
Users can browse coffee items, add them to the cart, and place orders.

---

## 🚀 Features

* User Registration & Login
* Coffee Menu Display
* Add to Cart
* View Cart
* Place Orders
* Order History
* Admin Panel for Managing Products

---

## 🛠 Technologies Used

* Python
* Django
* HTML5
* CSS3
* Bootstrap 5
* SQLite Database
* Git & GitHub
* Render (Deployment)

## ⚙️ Installation

1. Clone the repository

```
git clone https://github.com/yourusername/coffeecafe.git
```

2. Navigate to project folder

```
cd coffeecafe
```

3. Create virtual environment

```
python -m venv venv
```

4. Activate virtual environment

Windows:

```
venv\Scripts\activate
```

5. Install dependencies

```
pip install -r requirements.txt
```

6. Run migrations

```
python manage.py migrate
```

7. Start server

```
python manage.py runserver
```
